# TreZuzey3 – מידות, מטבעות וארמית

אפליקציית לימוד במראה, בצלילים ובאנרגיה של Cybertron3.
כל החומר לקוח מ-`c:\dev\docs\TREZUZEY\`.
בלי שמות קודש, בלשון צנועה, ובלי מושגים של עבודה זרה.

## המשחקים

**מידות, נפחים, שטחים ומטבעות**
- 🔢 כמה יש ב...? – כמה טפחים באמה, כמה קבין בסאה, כמה דינרים בסלע.
- ⚖️ נאה או חזון איש? – הערך של כל מידה לפי כל שיטה. מטבעות בגרם לפי הרמב"ם.
- 🧮 מחשבון חז"ל – מקלידים מספר (טפחים, ס"מ, סמ"ק, גרם כסף).
- 🪜 סולם המידות – מסדרים מהקטן לגדול.

**חידות משעשעות**
- 🤔 לא פשיטא – "יוסי קנה תפוח בשני סלעים ושילם רק 3 שקלים – כמה מעות עוד חסר?"
  המספרים, השמות והחפצים מתחלפים בכל משחק. יש חידות על מטבעות, אורך, מרחק וזמן, נפח, שטח ומשקל.
  בשלב האחרון מקלידים את התשובה.

**שיעורים בהלכה, במקרא ובזמנים**
- 📚 שיעורים בהלכה – סוכה, מחיצה, קידוש, חלה, פדיון הבן, שמות מן המקרא, זמנים והשיטות.

**ארמית – מילים ומונחים**
- 🧩 המילים הקטנות · 🗣️ שקלא וטריא · 🔠 ראשי תיבות · 💬 פתגמים · ☕ ארמית בדיבור
- 🧱 סדרו את הפתגם – בונים את המשפט בארמית לפי הסדר.

**משחקים מהירים**
- 🃏 זוגות ומשחק זיכרון · ⚡ מירוץ 60 שניות

כל שלב נותן עד 3 כוכבים. הכוכבים נשמרים בדפדפן.
בכל כניסה מחכה חבר אחר (ינשוף, גמל, מאזניים...).

## הקבצים

| קובץ | מה יש בו |
|---|---|
| `index.html` | הדף הראשי |
| `style.css`, `trezuzey.css` | העיצוב (מ-Cybertron3) והתוספות |
| `core.js` | צלילים, קונפטי, כוכבים, מסכים |
| `quiz.js` | מנוע השאלות |
| `midot_data.js` | המידות והמטבעות (נכתב ביד מקבצים 01–04) |
| `data.js` | הארמית (נוצר אוטומטית מקבצים 10–14) |
| `midot.js`, `ladder.js`, `halacha.js` | משחקי המידות |
| `chidot.js` | החידות המשעשעות |
| `aramit.js`, `builder.js` | משחקי הארמית |
| `match.js`, `speed.js` | זוגות ומירוץ |

## עדכון הארמית

אחרי שינוי בקבצים 10–14 ב-`TREZUZEY`:

```
node build_data.js
```

ואז מעלים את מספר הגרסה (`?v=`) ב-`index.html`.
